# Olist E-commerce Data Analysis

## 📌 项目简介
基于 Kaggle 真实电商数据集（10万+订单），使用 MySQL 进行数据清洗与多表分析，并使用 Excel 完成可视化。

## 🛠️ 工具
* MySQL, Navicat
* Excel

## 📁 文件说明
* `SQL-Scripts/`: 数据库查询代码（包含月度趋势、地域分布、热销品类分析）
* `Excel-Data/`: 分析结果数据源
* `Report/`: 完整的 PDF 分析报告

## 💡 核心发现
1. 订单量在 2017 年爆发式增长。
2. 客户高度集中在 SP（圣保罗）州。
3. 床垫浴室桌布（bed_bath_table）是销量最高的品类。
