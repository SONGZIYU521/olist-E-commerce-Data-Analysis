# Olist E-commerce Data Analysis

## 📌 项目简介
基于 Kaggle 真实电商数据集（10万+订单），使用 MySQL 进行数据清洗与多表分析，并使用 Excel 完成可视化，输出具有商业洞察的分析报告。

## 🛠️ 工具
* MySQL, Navicat
* Excel

## 📁 文件说明
* `SQL-Scripts/`: 数据库查询代码
  * `01-03`：基础趋势、地域、品类分析
  * `04`：支付方式偏好与客单价分析
  * `05`：各州客户真实客单价排名（三表关联）
* `Excel-Data/`: 分析结果数据源
* `Report/`: 完整的 PDF 分析报告（已包含最新分析结论）

## 💡 核心发现
1. **订单趋势**：平台订单在 2017 年呈爆发式增长，于 2017 年 11 月达到峰值。
2. **地域分布**：客户高度集中在 SP（圣保罗）州，是平台核心市场。
3. **热销品类**：`bed_bath_table`（床垫浴室桌布）和 `health_beauty`（健康美容）是最受欢迎的两大品类。
4. **支付与客单价**：信用卡是主流支付方式；高客单价州往往订单量较少，建议关注高净值地区的精准营销。
